## 📊 Project Overview
**M3DP Filament Recommendation Engine** is an offline-first, single-file static web application designed to help 3D printing enthusiasts find the perfect filament.

- **Frontend**: Vanilla JS, HTML5, Tailwind CSS (CDN). Served via Jinja2 templates.
- **Backend**: FastAPI (`main.py`) running on Uvicorn.
- **Data**: Embedded CSV data (`data/raw/material_db.csv`).
- **State**: `v1.6.0` - FastAPI migration complete. Ecosystem menu added.
